# صفحة دردشة متطورة باستخدام HTML, CSS, و JavaScript

## مقدمة
هذه صفحة دردشة بسيطة ومتطورة تم تطويرها باستخدام **HTML**، **CSS**، و **JavaScript**. تتيح هذه الصفحة للمستخدمين إرسال واستقبال الرسائل في الوقت الفعلي، إضافة رموز تعبيرية، وتغيير حالة الاتصال الشخصية. كما تحتوي على إشعارات للرسائل الجديدة وحقل إدخال مرن.

## الميزات
- **إرسال واستقبال الرسائل**: يتيح للمستخدم إرسال الرسائل إلى الآخرين وعرض الرسائل المرسلة والمستقبلة.
- **إضافة الرموز التعبيرية**: يمكن للمستخدمين إضافة رموز تعبيرية إلى رسائلهم.
- **إشعارات الرسائل الجديدة**: تظهر إشعارات عند وصول رسالة جديدة.
- **تغيير حالة الاتصال**: يمكن للمستخدم تحديد حالته الشخصية (مثل "متصل" أو "مشغول").
- **دعم الرسائل التلقائية**: المحاكاة لرسائل من المستلم بعد إرسال رسالة.

## التقنيات المستخدمة
- **HTML**: لإنشاء هيكل الصفحة.
- **CSS**: لتصميم وتنسيق الواجهة بشكل مرن وجميل.
- **JavaScript**: لإضافة التفاعلية مثل إرسال الرسائل، إضافة الرموز التعبيرية، وعرض الإشعارات.
- **Media Queries**: لتحسين واجهة المستخدم للأجهزة الصغيرة مثل الهواتف المحمولة.

## كيفية الاستخدام
1. قم بتحميل جميع الملفات (HTML, CSS, JavaScript) إلى جهازك.
2. افتح ملف `index.html` في متصفحك.
3. استمتع بالدردشة وإرسال الرسائل!
4. يمكنك تغيير حالة الاتصال الخاصة بك، إضافة رموز تعبيرية، أو تغيير النص في حقل الإدخال.

## تشغيل المشروع على GitHub Pages
يمكنك نشر هذا المشروع على **GitHub Pages** باتباع الخطوات التالية:
1. قم بإنشاء مستودع جديد على GitHub.
2. قم بتحميل ملفات المشروع إلى المستودع.
3. في إعدادات المستودع، انتقل إلى قسم **GitHub Pages**.
4. حدد الفرع `main` وانقر على "Save".
5. سيكون لديك رابط يمكن الوصول إليه من الإنترنت لتصفح الصفحة.
